# Аналитика кредитных выдач в Астане (2023–2026)

**Учебный проект по Data Analytics в рамках программы TechOrda.**

## Цель проекта

Проанализировать динамику кредитных выдач в Астане, сравнить кредитные продукты и выявить тенденции, которые могут помочь в принятии бизнес-решений.

## Данные

- Период: 5 января 2023 года — 12 октября 2026 года.
- Количество записей: 4 049.
- Уникальных клиентов: 3 869.
- Количество менеджеров: 28.
- Общая сумма выдач: около 62,03 млрд ₸.

## Инструменты

- Python, Pandas, NumPy
- SQL и MariaDB
- Jupyter Notebook
- Matplotlib и Seaborn
- Scikit-learn
- Git и GitHub

## Этапы анализа

1. Очистка и подготовка данных.
2. Исследовательский анализ данных (EDA).
3. Расчёт бизнес-метрик.
4. Сравнение кредитных продуктов и периодов.
5. Проверка статистических гипотез.
6. Экспериментальное прогнозирование.
7. Визуализация результатов и подготовка бизнес-рекомендаций.

## Основные результаты

- Общая сумма выдач за анализируемый период составила около 62,03 млрд ₸.
- Залоговые займы формируют около 90,35% общей суммы выдач.
- В январе–сентябре 2026 года сумма выдач снизилась на 42,66% относительно аналогичного периода 2025 года.
- Статистический анализ выявил различия между кредитными продуктами и между годовыми периодами.
- Экспериментальная модель прогноза показала низкую точность и требует дальнейшего улучшения.
