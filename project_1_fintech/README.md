# Аналитика кредитных выдач в Астане (2023–2026)

**Data Analytics Portfolio Project** | Python · SQL · Pandas · Matplotlib · Seaborn · Scikit-learn · MariaDB

## 1. Бизнес-задача

Проанализировать динамику кредитных выдач в Астане за 2023–2026 годы, выявить изменения объёмов кредитования, сравнить кредитные продукты и сформулировать рекомендации для повышения эффективности продаж.

**Цель проекта:** использовать данные о кредитных выдачах для выявления бизнес-тенденций и поддержки принятия управленческих решений.

### Основные задачи

- Подготовить и проверить качество данных.
- Провести исследовательский анализ данных (EDA).
- Рассчитать ключевые бизнес-метрики.
- Сравнить показатели по годам и кредитным продуктам.
- Проверить статистические гипотезы.
- Построить экспериментальный прогноз.
- Сформулировать выводы и бизнес-рекомендации.

## 5. Проверка гипотез (Hypothesis Testing)

Для проверки гипотез применены непараметрические статистические тесты.

| Гипотеза | Метод | Результат | Вывод |
|---|---|---|---|
| Распределения сумм выдач различаются между годами за сопоставимые месяцы | Критерий Краскела — Уоллиса | p = 0,000182 | Статистически значимые различия обнаружены |
| Распределения сумм выдач отличаются между залоговыми и беззалоговыми займами | Критерий Манна — Уитни | p < 0,00000001 | Статистически значимые различия обнаружены |
| Существуют статистически значимые сезонные различия между календарными месяцами | Критерий Краскела — Уоллиса | p = 0,0929 | При уровне значимости 0,05 статистических доказательств сезонности недостаточно |

Статистическая значимость показывает наличие различий, но сама по себе не объясняет их причины и не доказывает причинно-следственную связь.

## 6. Прогнозирование (Forecasting)

Для экспериментального прогнозирования месячной суммы выдач использована модель линейной регрессии с временным индексом и признаками месяца.

- Период моделирования: 45 месяцев.
- Обучающая выборка: 36 месяцев.
- Тестовая выборка: 9 месяцев.
- Коэффициент детерминации: R² = −16,088.
- Средняя абсолютная ошибка: MAE ≈ 1,082 млрд ₸.

Отрицательный R² указывает на низкое качество модели на тестовой выборке. В текущем виде прогноз не рекомендуется использовать для принятия бизнес-решений. Для улучшения модели необходимы дополнительные признаки, анализ структурных изменений и сравнение с базовыми методами прогнозирования.

## 10. Ограничения анализа

- Данные за 2026 год неполные.
- Датасет отражает состоявшиеся выдачи, но не содержит полной воронки заявок, отказов и одобрений.
- Без данных о планах продаж нельзя полноценно оценить выполнение KPI.
- Наблюдаемые различия не доказывают причинно-следственную связь.
- Экспериментальная модель прогнозирования показала низкую точность.
- Результаты относятся к анализируемым данным Астаны и не должны автоматически распространяться на другие регионы.
