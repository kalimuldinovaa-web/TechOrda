# TechOrda — Data Analytics Portfolio

Портфолио учебных проектов, выполненных в рамках программы обучения **TechOrda**.

## Изучаемые инструменты и технологии

- **Python** — анализ данных и автоматизация.
- **Pandas, NumPy** — обработка и подготовка данных.
- **SQL, MariaDB** — запросы и анализ данных в базах данных.
- **Matplotlib, Seaborn, Plotly** — визуализация данных.
- **Jupyter Notebook** — проведение аналитических исследований.
- **Scikit-learn** — основы машинного обучения и прогнозирования.
- **Git, GitHub** — контроль версий и управление проектами.

## Учебные проекты

### Project 1 — Fintech Analytics

Анализ кредитных выдач в Астане за 2023–2026 годы.

Проект включает очистку данных, исследовательский анализ (EDA), расчёт бизнес-метрик, SQL-анализ, проверку статистических гипотез, визуализацию и подготовку бизнес-рекомендаций.

**Инструменты:** Python, Pandas, NumPy, SQL, MariaDB, Matplotlib, Seaborn, Scikit-learn.

## Цель портфолио

Продемонстрировать практические навыки анализа данных: от подготовки датасетов и исследования закономерностей до визуализации результатов и формирования рекомендаций на основе данных.

*Другие проекты будут добавляться по мере прохождения программы обучения.*
